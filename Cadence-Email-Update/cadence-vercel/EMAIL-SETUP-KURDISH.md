# چالاککردنی ئیمەیڵ بۆ Cadence

کۆد و پەڕەکان ئامادە کراون. هێشتا هیچ گۆڕانکارییەک لە Neon یان وێبسایتە بڵاوکراوەکەت نەکراوە و هیچ ئیمەیڵێکی واقعی نەنێردراوە.

## ١. بنکەدراوە نوێ بکەرەوە

**پێش بارکردنی کۆدی نوێ**، ناوەڕۆکی `database/002-account-email.sql` لە Neon SQL Editor جێبەجێ بکە. ئەمە خانە و خشتەی نوێ زیاد دەکات و هەژمار و تۆماری فێربوون ناسڕێتەوە. هەژمارە کۆنەکان بەخۆکار وەک ئیمەیڵی پشتڕاستکراوە تۆمار ناکرێن.

بۆ بنکەدراوەیەکی نوێ، `database/schema.sql` بەکار بهێنە؛ ئەوە جێگرەوەی migrationەکە بۆ بنکەدراوەی کۆن نییە.

## ٢. Resend بۆ ئیمەیڵی خۆت

١. لە https://resend.com/ هەژمارێک دروست بکە و ئیمەیڵەکەت پشتڕاست بکەرەوە.
٢. لە API Keys، کلیلی ناردنی ئیمەیڵ دروست بکە. بە نهێنی بیپارێزە؛ لە GitHub یان چات دایمەنا.
٣. بۆ تاقیکردنەوە `Cadence <onboarding@resend.dev>` بەکار بهێنە. ئەم نێرەرە تەنها بۆ ئیمەیڵی هەژماری Resendی خۆت کار دەکات. بۆ بەکارهێنەرانی تر پێویستە دۆمەینێکی خۆت پشتڕاست بکەیتەوە.

بەڵگەنامە: https://resend.com/docs/knowledge-base/403-error-resend-dev-domain

## ٣. ڕێکخستنی Vercel

لە Settings > Environment Variables:

| ناو | بەها |
| --- | --- |
| `RESEND_API_KEY` | کلیلی نهێنیی Resend؛ تەنها لە Vercel دایبنێ |
| `EMAIL_FROM` | `Cadence <onboarding@resend.dev>` بۆ تاقیکردنەوە |
| `SITE_URL` | `https://english-learning-project-eta.vercel.app` |
| `REQUIRE_EMAIL_VERIFICATION` | سەرەتا `false`؛ دوای تاقیکردنەوە `true` |

`DATABASE_URL`ی ئێستا بپارێزە. ئەم ناوانە بە `NEXT_PUBLIC_` دەست پێ مەکە.

## ٤. نوێکردنەوە و تاقیکردنەوە

١. ناوەڕۆکی پاکێجی نوێ لە GitHub جێگرەوەی فایلەکان بکە، فۆڵدەرەکانیش بار بکە. Vercel دەبێت نوێترین commit بڵاو بکاتەوە.
٢. بە هەمان ئیمەیڵی Resend، لینکی پشتڕاستکردنەوە داوا بکە. Inbox و Spam بپشکنە.
٣. لینکەکە بکەرەوە و وشەی نهێنییەکی نوێ دیاری بکە. دووبارە بە وشەی نهێنیی نوێ بچۆ ژوورەوە.
٤. «وشەی نهێنیت لەبیر چووە؟» تاقی بکەرەوە. لینکەکە ٣٠ خولەک کار دەکات و تەنها جارێک بەکار دێت.
٥. دوای گۆڕینی وشەی نهێنی، چوونەژوورەوە کۆنەکان کۆتایی دێن.
٦. دوای دڵنیابوون لە ناردنی ئیمەیڵ، `REQUIRE_EMAIL_VERIFICATION=true` بکە و Redeploy بکە. هەژمارە کۆنە پشتڕاستنەکراوەکانیش دەبێت پشتڕاستکردنەوە ئەنجام بدەن.

لینکی نوێ جێگرەوەی لینکی پێشووی هەمان جۆر دەبێت. کردنەوەی لینک بە تەنها هیچ گۆڕانکارییەک ناکات؛ تەنها دوای پاشەکەوتکردنی وشەی نهێنیی نوێ جێبەجێ دەبێت. گەڕاندنەوەی وشەی نهێنی بە تەنها ئیمەیڵی پشتڕاستنەکراوە پشتڕاست ناکاتەوە؛ لینکی پشتڕاستکردنەوەی جیاواز بەکار بهێنە.

## چاکسازیی ڕاستەوخۆ لەمەودوا

بۆ ئەوەی خۆم کۆد و بڵاوکردنەوە و ناردنی ئیمەیڵ بەڕێوە ببەم، GitHub و Vercel و Resend لەگەڵ Codex پەیوەست بکە. پەیوەستکردنی هەژمارەکان لەلایەن تۆوە ئەنجام دەدرێت؛ کلیلی نهێنی لە چات مەنووسە.
