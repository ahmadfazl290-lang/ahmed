# ڕێنمایی دانانی Cadence لە GitHub و Vercel

## ١. فایلەکان بخەرە GitHub

١. فایلە ZIPەکە بکەرەوە و بچۆ ناو فۆڵدەری `cadence-vercel`.
٢. لە GitHub کۆگایەکی نوێی **Private** دروست بکە؛ بۆ نموونە `cadence-english`.
٣. `Add file > Upload files` هەڵبژێرە و ناوەڕۆکی فۆڵدەری پڕۆژەکە بار بکە.
٤. `package.json` دەبێت لە سەرەتای کۆگاکە بێت، لە تەنیشت `app` و `components`؛ لە ژێر فۆڵدەرێکی زیادەدا مەیهێڵەوە.
٥. فایلەکانی `.gitignore` و `.env.example`یش دابنێ. ZIPەکە خۆی بار مەکە.

## ٢. بنکەدراوەی Neon ئامادە بکە

١. هەژمارێک لە https://neon.com/ دروست بکە و پڕۆژەیەکی نوێ بکەرەوە.
٢. لە `SQL Editor`، ناوەڕۆکی `database/schema.sql` دابنێ و جێبەجێی بکە.
٣. لە `Connect`، بەستەری پەیوەندیی بنکەدراوە وەربگرە. ئەم بەستەرە وشەی نهێنی تێدایە؛ لە GitHub یان چات دایمەنا.

## ٣. پڕۆژەکە بڵاو بکەرەوە

١. لە https://vercel.com/ بچۆ ژوورەوە.
٢. `Add New > Project` هەڵبژێرە و کۆگای GitHubەکەت هاوردە بکە.
٣. جۆری پڕۆژە `Next.js` و وەشانی Node.js `22.x` دیاری بکە.
٤. لە `Environment Variables`، `DATABASE_URL` زیاد بکە و بەستەری نهێنیی Neon تێیدا دابنێ.
٥. چونکە سەرەتا تەنها خۆت بەکاری دەهێنیت، `REGISTRATION_CODE`یش زیاد بکە و کۆدێکی تایبەت دیاری بکە. لە کاتی دروستکردنی هەژمار ئەو کۆدە بەکار بهێنە.
٦. AI جارێ ڕێک مەخە؛ بۆ کارکردنی وانە و هەژمار پێویست نییە.
٧. `Deploy` دابگرە؛ دوای تەواوبوون لینکێکی گشتی وەردەگریت.

## ٤. پشکنینی یەکەم

- هەژمارێک بە ئیمەیڵ و وشەی نهێنی دروست بکە.
- بچۆ دەرەوە و دووبارە بچۆ ژوورەوە.
- وانەیەک بکەرەوە و گۆڕانکارییەک پاشەکەوت بکە؛ پەڕەکە نوێ بکەرەوە و دڵنیابە داتاکە ماوە.
- دوگمەی تێپەڕاندنی تاقیکردنەوە تاقی بکەرەوە.

## شتە پێویستەکان

ئەم پاکێجە کۆدی وێبسایتەکەیە. هیچ هەژمارێکی Vercel، Neon یان GitHubی بۆت دروست نەکردووە و هێشتا بڵاو نەکراوەتەوە. هەژمارە ناوخۆییەکانت بەخۆکار ناگوازرێنەوە بۆ Neon؛ لە وەشانی نوێدا هەژمارێک دروست بکە.

AIی OpenAI هێشتا پەیوەست نەکراوە. بۆ پشتڕاستکردنەوەی ئیمەیڵ و گەڕاندنەوەی وشەی نهێنی، ڕێنمایی `EMAIL-SETUP-KURDISH.md` بەکار بهێنە؛ پێویستی بە migration و خزمەتگوزاری ناردنی ئیمەیڵ هەیە.

ئەگەر نامەی `database is not configured` ببینیت، `DATABASE_URL` بپشکنە. ئەگەر بنکەدراوە پەیوەستە بەڵام هەژمار دروست نابێت، دڵنیابە `schema.sql`ت جێبەجێ کردووە. دوای گۆڕینی ڕێکخستنەکان، `Redeploy` بکە.
