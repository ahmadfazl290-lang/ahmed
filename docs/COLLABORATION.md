# Collaboration

Use docs/GITHUB-HANDOFF.md for the proposed shared baseline and ownership rules. Every change should identify its UI/security/storage impact, list reviewed shared files and attach exact validation results. Separate mocked/transport/browser tests from authorized live checks. UI contributors must not replace Supabase with legacy or local password/session logic. Authentication contributors coordinate navigation/presentation changes with the UI owner. Keep internal cadence:* identifiers and stored records unchanged. Document newly discovered conflicts before widening scope.
